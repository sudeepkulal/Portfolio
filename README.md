# Sudeep Kulal — Portfolio

Personal portfolio website built with React + Vite, showcasing my projects, skills, and experience as a Full Stack & Android Developer.

🔗 **Live site:** [sudeepkulal.vercel.app](https://sudeepkulal.vercel.app)

---

## Tech Stack

- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Smooth scroll:** React Scroll
- **Hosting:** Vercel

---



## Running Locally

```bash
# Clone the repo
git clone https://github.com/sudeepkulal/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
```

Output goes to the `dist/` folder.
